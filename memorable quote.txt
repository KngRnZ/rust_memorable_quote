Cargo also provides a command called cargo check. 
This command quickly checks your code to make sure it compiles but doesn’t produce an executable.

In fact, to work on any existing projects, 
you can use the following commands to check out the code using Git, change to that project’s directory, 
and build:
$ git clone example.org/someproject
$ cd someproject
$ cargo build

Constants are valid for the entire time a program runs, 
within the scope in which they were declared. 
This property makes constants useful for values in your application domain that multiple parts of the program might need to know about, 
such as the maximum number of points any player of a game is allowed to earn, or the speed of light.


Expressions implicitly return the unit () value if they don’t return any other value.
